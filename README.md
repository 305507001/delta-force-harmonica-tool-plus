## 这是什么

有两种玩法：

- **演奏**：程序模拟键盘和鼠标，在游戏里把曲子自动"吹"出来。
- **跟弹**：程序**一个键都不按**，只在游戏画面上浮出一个提示小窗，告诉你下一个该按哪个键、
  要不要按住鼠标键，你自己吹；还会判断你按得准不准。想自己学会吹，用这个。

不需要懂乐理，也不需要去找 MIDI 文件——曲库里已经内置了 8 首经典曲子，点一下就能吹。

> **别名 / 搜索关键词**：三角洲口琴工具 · 自动口琴脚本 · 三角洲行动口琴 · 口琴自动演奏 ·
> 键位自定义口琴 · Delta Force harmonica · harmonica auto player · MIDI 自动演奏脚本 · 零依赖 Python 小工具

> 如果你只是想看看效果、又不想真的进游戏，直接双击 **`功能展示.html`** ——
> 那是个可点、可发声的网页版演示，跟程序功能一一对应。

## 一、快速开始（小白看这一节就够了）

### 三种用法，挑一种

| 用法 | 要装 Python 吗 | 设置和曲子存在哪 |
|---|---|---|
| **免安装版**（推荐）：下载 `KouqinStudio-v*-portable.zip`，解压后双击 `口琴工坊.exe` | 不用 | 同文件夹的「数据」里，拷走整个文件夹就带走了 |
| **安装包**：下载 `KouqinStudio-v*-setup.exe`，装好后从开始菜单 / 桌面打开 | 不用 | `%LOCALAPPDATA%\KouqinStudio` |
| **源码运行**：下载整个仓库，双击「启动.bat」（下面详细说） | 要 | 同文件夹的「数据」里 |

免安装版和安装包在本仓库的 Releases 页面下载。exe 会申请管理员权限（游戏收模拟按键需要），
双击时弹 UAC 点「是」。exe 没有数字签名，第一次运行如果出现「Windows 已保护你的电脑」，
点「更多信息」→「仍要运行」；杀毒软件也可能误报（它会读键盘状态、模拟按键），不放心就用源码运行。

下面以源码运行为例；用 exe 的话把「双击启动.bat」换成「双击口琴工坊.exe」就行。

### 前提：装 Python

需要电脑上有 **Python 3.9 或更高版本**。没有的话去
[python.org](https://www.python.org/downloads/) 下载安装，
**安装时一定要勾选 `Add Python to PATH`**。

> 怎么确认装好了？按 `Win + R`，输入 `cmd` 回车，在黑窗口里输入 `python --version`，
> 能显示版本号就行。

### 然后三步

```
第 1 步   双击「启动.bat」
          （会自动申请管理员权限，弹 UAC 窗口点「是」）

第 2 步   在「曲库」页，点一首曲子的「演奏」按钮
          （内置 8 首曲子，不用自己准备文件）
          想自己吹就点旁边的「跟弹」

第 3 步   看到倒计时就开始吹了，这时点一下游戏画面
          （游戏要设成「窗口化」或「无边框窗口化」）
```

想停就按 **`F8`**，或者点右上角的「停止演奏」。

> **第一次打开会弹两个窗口**：
> ① 使用须知（看完点「我已阅读并同意」）
> ② 使用步骤（看完点「知道了，开始玩」）
>
> 之后想再看使用步骤，点右上角的 **`?`** 按钮就行。

### 游戏里没反应？按顺序查这 5 条

1. 是不是双击「启动.bat」启动的？（不是管理员的话游戏收不到按键）
2. 游戏是不是设成了「窗口化」或「无边框窗口化」？（全屏独占收不到）
3. 游戏窗口是不是在最前面？（倒计时时点一下游戏画面）
4. 输入法是不是切成英文了？（中文输入法会拦掉按键）
5. 上面都对了还是漏音 → 到「设置」页把节奏档调成 **「稳健」** 再试

> 还是有奇怪问题？双击 **「诊断启动.bat」** —— 它会保留一个黑窗口，
> 里面能看到具体报什么错，截图发出来就能定位。

## 二、四个页面

程序只有四个页面，左上角切换。

### 🎵 曲库 —— 点一下就吹

列出本地所有曲子，每首一行：

```
♪  小星星   12 小节 · 47 个音 · 约 29 秒 · 100 拍/分  跟弹难度 ★★☆☆☆   [删除] [编辑] [跟弹] [演奏]
```

- **演奏**：开始自动吹奏。播放时底部会显示进度、暂停 / 继续和停止按钮
- **跟弹**：游戏画面上浮出按键提示，你自己按（见下面「跟弹模式」）。星级是估出来的跟弹难度
- **编辑**：跳到「谱曲」页修改
- **导入曲谱**：别人给你的 `.json` 曲谱文件拖进来就能用
- **恢复内置曲目**：内置曲子被删了可以一键补回来

### ✏️ 谱曲 —— 点格子编曲子（不用懂音乐）

界面就是一张格子表，**每小节几拍，每一拍一个格子**。

```
  1   [ 1 ] [ 1 ] [ 5 ] [ 5 ]
  2   [ 6 ] [ 6 ] [ 5 ] [ · ]
  3   [ · ] [ · ] [ · ] [ · ]
```

- **点任意一个格子**，弹出选音面板
- 面板里先选音高（低音 / 中音 / 高音 / 更高），再点要用的音
- 每个音按钮上都写着**要按哪个键**，选完一看就知道怎么弹
- 想空一拍就选「休止」
- **连续两格填同一个音 = 一个长音**，不用专门设

顶部可以改曲名、选速度（很慢 / 慢 / 中速 / 稍快 / 快）、改每小节拍数。
底部有「+ 加一小节」「- 减一小节」「试听」「保存」「保存并演奏」。

格子按音高上色，一眼就能看出音的高低：

| 颜色 | 音高 |
|---|---|
| 🔵 蓝 | 低音 |
| 🟢 绿 | 中音 |
| 🟠 橙 | 高音 |
| 🟣 紫 | 更高 |

### 🎯 跟弹模式 —— 看着提示自己吹

点曲子的「跟弹」后，屏幕上会浮出一个半透明的小窗（第一次在屏幕下方居中，可以拖到别处）：

```
┌──────────────────────────────────────────────────────────┐
│ [跟弹] 小星星                        命中 12 · 漏 1   00:12 │
│ ┌────────────┐ ║                                          │
│ │ 鼠标  现在  │ ║(X)━━━   (C)━━   (V)━━━━━━   (,)━━          │  ← 音符从右往左走，
│ │ 图标  按住  │ ║                                          │    走到竖线时按下
│ └────────────┘ ║                                          │
│        [Z] [X] [C] [V] [B] [N] [M] [,]                    │  ← 下一个要按的键会亮
└──────────────────────────────────────────────────────────┘
```

- **音符颜色 = 要按住哪个鼠标键**：绿 = 不按，蓝 = 降八度那个键（默认左键），橙 = 升八度那个键（默认右键），
  带紫色 **#** 的再加按升半音那个键（默认中键）。左边的鼠标图标实时显示"现在该按住哪个"
- **判定**：离音符起点 ±80ms 内算「完美」，±160ms 内算「不错」，过了还没按对算「漏」；
  按错了不会马上判死，窗口关闭前改按对照样算
- **等我按对再继续**（设置里打开）：每个音都停下来等你按对，不考节奏，适合第一次练
- **跟弹速度**（设置里）：0.5× ~ 1.0×，只影响跟弹，不影响自动演奏
- 自动演奏时默认也会显示这个小窗，提示程序正在按什么（设置里可以关）

> **这个小窗不碰游戏**：它只是本程序自己的一个置顶、半透明窗口，**不读写游戏内存、不注入游戏进程、
> 不截屏、不装键盘钩子**；跟弹时判断你按了什么，用的是和 F6/F8 热键一样的 `GetAsyncKeyState` 读状态位，
> 你的每一下按键游戏都照常收到。锁定后鼠标点击直接穿透到游戏，它也永远不会抢走游戏的焦点。
> 游戏要设成「无边框窗口化」或「窗口化」——全屏独占模式下任何窗口都盖不到游戏上面。
>
> 不过，没人能替任何一款反作弊保证它"怎么看待"一个置顶窗口；而且按许可协议，
> **本项目的任何部分（包括跟弹）都不能在在线对局里用**。

### ⚙️ 设置 —— 键位想换就换

**音键设置**：默认就是游戏里那套（`Z X C V B N M 逗号`）。
如果你改过游戏内键位，或者有自己顺手的键，点对应按钮再按一下键盘就行。

- 新键如果已经被别的音占用了，**两个音会自动对调**，不用手动改两次
- 录入期间全局热键会临时停用，免得按 `F6` 时突然开始演奏

**变调鼠标键**：口琴靠按住鼠标键来升降调，这里可以换键或者关掉某一档。

**演奏设置**：

- **节奏档**：游戏里漏音（按了却没响）就往上调一档
  - 稳健 —— 余量最大，适合低配机、帧数不稳
  - 标准 —— 默认，大多数情况够用
  - 灵敏 —— 节奏最紧，适合快歌
- **倒计时**：开始前留几秒让你切回游戏

**悬浮提示窗**：自动演奏时要不要显示、等我按对再继续、跟弹速度、提前显示几秒、大小、不透明度、
要不要显示下面的键盘行。点「调整位置 / 预览」后小窗会解锁并播放演示，用鼠标拖到合适的位置，
双击它（或再点一次按钮）锁定。改外观时小窗上当场能看到效果，点「保存设置」才生效。

### 🔧 进阶 —— 给愿意折腾的人

默认不加载，点进去才创建。里面有：

- **打开 MIDI**：导入 `.mid / .midi / .kar / .rmi`，自动挑出主旋律轨
- **简谱写谱**：用文本写谱，比点格子快
- **钢琴卷帘**：可视化改谱，拖动改音高和时间，双击加音，`Delete` 删音
- **跟弹这一段**：导入的 MIDI 也能跟弹，倍速用本页工具栏上的值
- **存进曲库**：把导入的 MIDI 旋律量化成格子谱，之后就能像普通曲子一样点播
- **导出**：通用按键表 `.csv`、罗技 G HUB 脚本 `.lua`、结构化 `.json`

## 三、默认键位

游戏里那把口琴的规则是：**一排 8 个音键 + 鼠标变调**。

| 音名 | do | re | mi | fa | sol | la | si | 高 do |
|---|---|---|---|---|---|---|---|---|
| 按键 | `Z` | `X` | `C` | `V` | `B` | `N` | `M` | `,` |

| 按住 | 效果 |
|---|---|
| 鼠标左键 | 整排降一个八度 |
| 鼠标右键 | 整排升一个八度 |
| 鼠标中键 | 整排升半音 |

能吹出来的范围是 **低音 do ~ 高高音 #do**（约 C3 ~ C#6，共 38 个音高）。
超出这个范围的音，程序会自动**折叠到最近的可用八度**，旋律不会断。

程序里的按键显示长这样：`Z` = 直接按 Z；`R+,` = 按住右键再按逗号；`M+Z` = 按住中键再按 Z。

> 完整的 38 个音高对照表在「进阶」页可以导出。

## 四、游戏里必须注意的事

| 事项 | 说明 |
|---|---|
| **管理员权限** | 不管理员运行的话，游戏会收不到模拟按键（Windows 的 UIPI 限制） |
| **窗口化** | 游戏要设成「窗口化」或「无边框窗口化」，全屏独占收不到模拟按键 |
| **游戏在前台** | 倒计时结束前点一下游戏画面，确保它在最前面 |
| **输入法切英文** | 中文输入法会拦掉按键 |
| **原地别动** | 按住 `W/A/S/D` 时键盘矩阵会吞掉部分音键（硬件限制，全键无冲键盘可以避免） |
| **出问题就按 F8** | 任何时候按 `F8` 立即停止并松开所有按键 |

## 五、快捷键

| 键 | 作用 |
|---|---|
| `F6` | 空闲时=开始；演奏中=暂停；暂停中=继续；倒计时中=取消（跟弹同样适用） |

## 六、命令行用法

不想开界面的时候：

```bash
python 口琴工坊.py                    # 打开图形界面
python 口琴工坊.py 某首歌.mid          # 带谱启动，直接进进阶页

python 口琴工坊.py --tunes           # 列出曲库
python 口琴工坊.py --play-tune 小星星 # 直接演奏曲库里的曲子
python 口琴工坊.py --play 某首歌.mid  # 演奏 MIDI
python 口琴工坊.py --tracks 某首歌.mid # 看看这个 MIDI 有哪些音轨
python 口琴工坊.py --keytable        # 导出 38 个音高的键位对照表
python 口琴工坊.py --selftest        # 核心自检
```

也可以把 MIDI 文件直接拖到「拖拽演奏.bat」图标上。

## 八、技术要点（给想看代码的人）

### 为什么用 SendInput 的扫描码模式

很多自动化工具用 `keybd_event` 或虚拟键码，游戏里往往完全没反应。
因为游戏走的是 RawInput / DirectInput 路径，读的是**硬件扫描码**。
本程序标记 `KEYEVENTF_SCANCODE` 直接投递扫描码，兼容性最好。

> 注意（修改版补充）：原文这里写的是"和真实键盘按下时产生的数据包一致"，这不准确。
> `SendInput` 注入的事件在系统层面带有"注入"标记（例如低级键盘钩子能看到 `LLKHF_INJECTED`），
> Raw Input 里也没有对应的物理设备，反作弊完全可以把它和真实按键区分开。
> **自动演奏有被检测、被封号的真实风险**；跟弹模式不注入任何按键。

### 三种时序余量

游戏是按渲染帧读键盘的。如果鼠标修饰键和音键的按下时间差小于一帧（60FPS ≈ 16.7ms），
游戏可能读到「修饰键还没生效」的那一帧，音就吹错八度甚至不响。

所以所有时序参数都以帧为单位：

| 档位 | 修饰键提前 | 最短按住 | 音符间隔 |
|---|---|---|---|
| 稳健 | 2 帧 | 2 帧 | 2 帧 |
| 标准 | 1 帧 | 1.2 帧 | 1 帧 |
| 灵敏 | 0.5 帧 | 1 帧 | 0.5 帧 |

**最小间隔按物理毫秒计算，不随播放速度压缩**——倍速只压缩音符本身的时长，
这些保命余量不动。

### 单声部槽位排布

口琴一次只能发一个音。和前一个音重叠、或者首尾紧贴留不出间隔的音，优先把**前一个音缩短**
到刚好空出间隔（但绝不短于"最短按住"，所以不会切出零时长的按键）；实在缩不出来（比如和弦），
才把这个音**顺延**到前一个音之后。

（修改版修正：原来的写法一律顺延，首尾紧贴的连奏每个音都晚一个间隔，乐句越吹越慢，
遇到休止符才追回来。现在内置曲目每个音都落在谱面时间上。）

### 暂停 / 定位后补按修饰键

修饰键是"差分"发送的——只在组合变化时才有鼠标事件。暂停和定位会先松开全部按键，
所以继续之前播放器会按事件流算出"此刻本该按着哪些鼠标键"，把它们按回去。
（修改版修正：原来不补，暂停后同一组合的音会整段吹错八度。）

### 跟弹的等待闸门

「等我按对再继续」靠播放器的等待闸门：时钟走到下一个还没按对的音就原地停住（状态仍是"演奏中"，
不松任何键），按对后闸门挪到下一个音，时钟从停下的地方接着走，不会跳。

### 修饰键差分切换

连续多个音用同一套修饰键时，引擎只在组合真正变化时才发鼠标事件，
既不浪费注入量，也减少抖动。

### 八度折叠

超出音域的音会整体平移若干个八度，落到音域内**同时保持音级关系**（比如 E7 → E5）。
这样旋律的调性和走向都不会被打乱，比直接丢掉这些音体验好得多。

### 零依赖

整个程序**只用 Python 标准库**：
`ctypes` 调 Windows API，`tkinter` 做界面，MIDI 解析是自己写的（两遍法解析 + 变速时间轴）。
不需要 `pip install` 任何东西，拷到有 Python 的机器上就能跑。

## 十、常见问题

**Q：点了演奏，游戏里一点反应都没有**
按顺序排查：① 是不是双击「启动.bat」启动的（要管理员权限）？
② 游戏是不是「窗口化」模式？③ 游戏窗口是不是在最前面？
④ 输入法是不是切到英文了？⑤ 把设置里的节奏档调到「稳健」再试。
（详细版见前面「游戏里没反应？按顺序查这 5 条」）

**Q：有些音吹不出来 / 吹错音**
说明游戏的按键读取比你的机器帧率还快，把节奏档调到「稳健」。
另外确认游戏内键位没被你自己改过——改过的话到设置页把程序里的键位也改成一致的。

**Q：快捷键 F6/F8 没反应**
别的程序可能占用了这些键。可以关掉占用的程序，或者直接在界面上点按钮。

**Q：试听没声音**
系统里没有可用的 MIDI 输出设备。不影响正常演奏，只是听不到预览。

**Q：怎么把我的曲子分享给别人**
`数据/曲库/曲名.json` 这个文件直接发给对方，在曲库页点「导入曲谱」即可。

**Q：跟弹的悬浮窗看不到**
游戏是不是全屏独占？换成「无边框窗口化」。还看不到就去「设置 → 悬浮提示窗」点「恢复默认位置」，
再点「调整位置 / 预览」确认它在屏幕上的哪里。

**Q：悬浮窗挡住了鼠标点击**
正常锁定状态下点击是直接穿透的；如果你刚在设置里点了「调整位置」，双击小窗锁定即可。
开始演奏 / 跟弹时也会自动锁定。

**Q：跟弹判定总说"鼠标键不对"**
要先按住鼠标键再按音键（和游戏里一样），而且只按要求的那几个。左边的鼠标图标会实时显示该按哪个，
你按着的键会描白边（按多了描红边）。

**Q：按住 W/A/S/D 走路时漏音**
这是键盘硬件限制（键盘矩阵冲突），全键无冲（NKRO）键盘可以避免。演奏时站着别动就好。
